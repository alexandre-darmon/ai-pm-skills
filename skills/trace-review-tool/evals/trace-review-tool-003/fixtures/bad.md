# Brief for the coding agent

Build a single-page app that loads last month's raw alert export (names, IBANs, amounts) from a local file on the head of compliance's laptop. Since it never leaves the building, encryption of the laptop disk is enough.

Show each summary next to the original alert. Two buttons: pass and fail. No accounts: anyone can open it. Save results to a CSV in the same folder, which the team can share on Teams.
