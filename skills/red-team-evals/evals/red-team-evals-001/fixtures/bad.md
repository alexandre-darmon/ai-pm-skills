# Security testing for the claims assistant

Your developers already tried 30 jailbreaks and none got through, which is a good start. To strengthen this:

1. Run an automated scanner against the assistant with a few hundred jailbreak prompts.
2. Ask the CISO's team to try prompt injection for a week.
3. Add input filters and an output filter for personal data.
4. Report to model risk that the assistant resisted all jailbreak attempts and passed security testing, with the list of prompts used.
