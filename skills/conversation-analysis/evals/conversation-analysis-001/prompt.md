Our HR assistant has handled about 30,000 employee conversations since January. We want to know what people use it for, so tomorrow two HR assistants start labelling 200 conversations with this list of use cases:

Leave request · Holiday balance · Absence · Sick leave · Expenses · Travel booking · Travel expenses · Payslip · Salary questions · IT access · Password reset · Onboarding · Other · General question

Can you check the list before they start?
