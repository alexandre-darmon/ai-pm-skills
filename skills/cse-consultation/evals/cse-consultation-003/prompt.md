We are an insurer with about 120 employees in France. Our claims handlers will use an AI assistant that summarises claim files and drafts letters. Its admin dashboard shows, for each handler, the number of prompts, the drafts accepted and the time saved.

Management says it will not use the dashboard to evaluate anyone, so we only plan to present the tool to the CSE as general information. Is that enough?
