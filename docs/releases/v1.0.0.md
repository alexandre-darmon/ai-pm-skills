# AI PM Skills v1.0.0

**Evals as evidence.** 27 Agent Skills for AI product managers who build, in regulated European companies. Every skill in this release has a recorded eval run on exactly the text you download, with and without the skill, and passes it.

## What is in it

Four blocks, drawn as a loop:

| Block | Skills |
| --- | --- |
| **Specify**: should we use AI, and what does "correct" mean? | `ai-opportunity-assessment`, `llm-feature-prd`, `process-ai-redesign`, `ai-data-requirements`, `ai-interaction-patterns` |
| **Build**: build to learn, then hand over to engineers | `ai-feasibility-spike`, `system-prompt-and-guardrails`, `agent-design-and-tooling`, `trace-review-tool`, `prototype-handover` |
| **Evaluate**: does it work, before and after release? | `error-analysis`, `build-evals`, `llm-judge-calibration`, `synthetic-eval-data`, `agent-evals`, `retrieval-evaluation`, `model-selection`, `ai-vendor-evaluation`, `release-to-production`, `production-evals-monitoring`, `conversation-analysis` |
| **Prove**: what does a correct answer cost, and what will the regulator ask? | `assistant-kpis-cost-per-outcome`, `ai-roi-quantification`, `ai-act-classification`, `model-card-ai-registry`, `ai-incident-playbook`, `ai-adoption-plan` |

Six skills read the law (`legal`): they output checklists and questions for counsel, never a verdict, with a 0.90 pass bar and no LLM grader.

## The evidence

Same cases, Sonnet 5.5 answering, 3 runs per case:

- **Regex graders, 27 skills, 100 cases:** 52% with the model alone, 96% with the skill: **+44 points [+41, +48]**. Against the skill's own output template alone: +17 points [+6, +32].
- **Red lines held** (the one thing an answer must never do): 72% alone, **100%** with the skill.
- **Cost per correct answer**, API equivalent, 20 skills: $0.097 alone, $0.076 with the skill.
- **Routing**: with all 27 skills installed together, 49 requests aimed at known collision zones picked the expected skill, or none, in **147 of 147 runs**.
- **Stays silent** on near-miss requests in every negative case.

Limits, stated plainly: the regex graders and routing requests were written by the author and favour the skill; a blind LLM judge saw a smaller gain (about +10 points) on earlier runs and is not calibrated on human labels yet. Per-skill numbers: [skill-eval-gains.md](../../skill-eval-gains.md). Method: [docs/evaluation.md](../evaluation.md).

## Install

- **Claude Code**: `claude plugin marketplace add alexandre-darmon/ai-pm-skills`, then `claude plugin install ai-pm-skills@ai-pm-skills` (all) or `claude plugin install <skill>@ai-pm-skills` (one).
- **claude.ai, the Claude apps, the Skills API**: download a `<skill>-<version>.zip` from this release and upload it. Each zip is one skill folder, without its eval cases, with its CC BY 4.0 licence.
- **Other agents**: every folder follows the [Agent Skills](https://agentskills.io) standard and passes `skills-ref validate`.

`SHA256SUMS` lists the checksum of every zip.
