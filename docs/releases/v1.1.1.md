# AI PM Skills v1.1.1

A packaging release: the 29 skills and their evidence are the same as in [v1.1.0](v1.1.0.md). It brings the install routes for agents other than Claude into a tagged release.

## What changed

- **Install on 12 agents, one short route each.** The README's Install section gives one or two commands per tool: Claude Code, claude.ai and the Claude apps, OpenAI Codex, Cursor, GitHub Copilot, Gemini CLI, Google Antigravity, Windsurf (Devin), Kiro, OpenCode, Command Code, and other agents through the skills CLI. Scopes, single skills, updates and limits are in [docs/install.md](../install.md).
- **Manifests for the tools that need one**: Codex (`.agents/plugins/marketplace.json`, `.codex-plugin/plugin.json`), Gemini CLI (`gemini-extension.json`) and Antigravity (`.antigravity-plugin/plugin.json`). Codex now installs with:

  ```bash
  codex plugin marketplace add alexandre-darmon/ai-pm-skills --ref v1.1.1
  codex plugin add ai-pm-skills@ai-pm-skills
  ```

- **One version everywhere.** Every manifest carries 1.1.1, the validator checks they agree, and the release workflow refuses a tag that does not match them. Codex, Gemini CLI and Antigravity read this version to decide that an update exists.
- **Evals chart** shows the model alone and with the skill only.

## The evidence

Unchanged from v1.1.0: 29 skills, 109 cases × 3 runs, Sonnet 5.5; regex graders 52% alone, 96% with the skill, **+45 points [+41, +48]**; red lines held 100% with the skill; 172 of 174 routing runs correct with all 29 skills installed. The evals ran on Claude only: other agents may route and follow the skills differently. Only the Claude Code and claude.ai install routes were run on this repo; the others follow the vendors' docs.

## Install

Pin this release: `claude plugin marketplace add alexandre-darmon/ai-pm-skills#v1.1.1` (Claude Code), `--ref v1.1.1` (Codex), or download a `<skill>-1.x.y.zip` below for claude.ai and the Skills API. `SHA256SUMS` lists the checksum of every zip.
