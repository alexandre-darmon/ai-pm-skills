# AI PM Skills v1.1.0

**Evals as evidence.** 29 Agent Skills for AI product managers who build, in regulated European companies. Every skill in this release has a recorded eval run on exactly the text you download, with and without the skill, and passes it.

## New in v1.1.0

Two skills join the Evaluate block (29 of the 30-skill cap):

- **`red-team-evals`**: plan and read an attack campaign on an assistant or a RAG feature. Attack classes from the feature's own risks, checked against OWASP, ATLAS and NIST for coverage; each class sized on the Wilson bound; attack success rate per class with its interval, counted per attack, not per run; who red-teams and how independent they are; attacks used for tuning kept apart from held-out ones; found attacks become regression cases; a residual-risk record for AI Act art. 9 and 15. It never concludes "robust". An agent acting on injected content stays with `agent-evals`. Model alone 49%, with the skill 96%, gain +47 points (every case +30 to +64).
- **`multi-turn-evals`**: evaluate whole conversations, not single answers. Scripted and simulated multi-turn cases, a user simulator validated against real conversations before it is trusted, conversation-level graders (constraints kept, no contradiction, recovery after a correction), the drop from single-turn to multi-turn measured on the same tasks, and pass^k per conversation. Model alone 43%, with the skill 93%, gain +50 points.

Also changed:

- **`system-prompt-and-guardrails`**: its description now covers role-play tricks, leaks and a guardrail that refuses too much. Rerun, pass.
- **`ai-feasibility-spike`**: two stronger eval cases; the cases that barely separated the arms (+3, +5) now show +37 and +36.
- **Routing**: 58 requests on known collision zones; with all 29 skills installed together, 172 of 174 runs picked the expected skill, and the 2 misses fired no skill at all.

## The evidence

Same cases, Sonnet 5.5 answering, 3 runs per case:

- **Regex graders, 29 skills, 109 cases:** 52% with the model alone, 96% with the skill: **+45 points [+41, +48]**. Against the skill's own output template alone: +17 points [+6, +32].
- **Red lines held:** 71% alone, **100%** with the skill.
- **Cost per correct answer**, API equivalent, 22 skills: $0.097 alone, $0.076 with the skill.
- **Stays silent** on near-miss requests in every negative case.

Limits, stated plainly: the regex graders and routing requests were written by the author and favour the skill; a blind LLM judge saw a smaller gain (about +10 points) on earlier runs and is not calibrated on human labels yet (a blind human rating is under way). Per-skill numbers: [skill-eval-gains.md](../../skill-eval-gains.md). Method: [docs/evaluation.md](../evaluation.md).

## Install

- **Claude Code**: `claude plugin marketplace add alexandre-darmon/ai-pm-skills#v1.1.0`, then `claude plugin install ai-pm-skills@ai-pm-skills` (all) or `claude plugin install <skill>@ai-pm-skills` (one).
- **claude.ai, the Claude apps, the Skills API**: download a `<skill>-<version>.zip` from this release and upload it. Each zip is one skill folder, without its eval cases, with its CC BY 4.0 licence.
- **Other agents**: every folder follows the [Agent Skills](https://agentskills.io) standard and passes `skills-ref validate`.

`SHA256SUMS` lists the checksum of every zip.
